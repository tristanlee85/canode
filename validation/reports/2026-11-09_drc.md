## Changes made
All were tested on a scratch copy first, then applied. Afterwards: `make check` (pins 28/28, ERC 0 errors, DRC 0 errors, parity clean) and `make fab` (CPL identical to the committed rev A one, so no part moved).

1. **Clearance (0.157 mm, rule 0.2 mm):** GND stitching via (no tracks attached) next to the 0.5 mm VBATF track moved
   from (106, 133) to **(105.8, 132.8)**, giving ~0.37 mm clearance. Four other candidate positions were also clean.
2. **Starved thermal, U5 pin 2 (GND):** pad zone connection set to **solid**. Normal for a reflowed SOIC ground pin.
3. **Silk overlap:** Y1 reference label moved 2.2 mm left. (Trialled 7 positions; others hit pads or C6.)
4. **Format upgrade:** `kicad-cli sch|pcb|sym upgrade`. Schematic, board and project symbol library are now KiCad 10 format.
5. **Net names (`net_conflict`):** the generator named board nets `VIN`, `GND`, …; KiCad names local-label nets `/VIN`, ….
   All 45 board nets were renamed to the names in KiCad 10's own netlist export (every board net had an exact `/`-prefixed match).
   The 24 schematic no-connect pins got their `unconnected-(…)` net names via KiCad's Python API (`pcbnew`, bundled with KiCad 10).
6. **Net-class trap, fixed first:** the net-class patterns were exact names (`VBATF`, `VIN`, `GND`, …). Tested on a scratch copy:
   renaming VBATF to `/VBATF` made the pattern stop matching. VBATF silently fell back to the Default class (0.15 mm), and the
   clearance error *disappeared without being fixed*. So `/`-prefixed patterns were added for all seven power/supply nets
   in `canode.kicad_pro` (old ones kept). Verified: the clearance error still reported with the new names until the via was moved.
7. **Footprint fields:** Datasheet, LCSC, MPN and JLC fields copied from the symbols to the footprints (what F8 does), via `pcbnew`.
8. **BOM flags:** the board excluded J2–J5 and JP1/JP2 from the BOM; the schematic included all six. Resolved by intent:
   J2–J5 are real purchased connectors (now in BOM on both sides); JP1/JP2 are bare-copper solder jumpers with nothing to buy
   (schematic set to `in_bom no`). The JLC files are unaffected: `jlc_fab.py` selects assembled parts by the `LCSC` field.

Because of 5, 7 and 8, *Update PCB from Schematic* (F8) currently has nothing left to do.
